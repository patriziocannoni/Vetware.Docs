# Vetware — Documentação de Produto

Este repositório é a fonte funcional da Vetware. A documentação é
organizada por domínio de produto para permitir especificação, implementação e
validação independentes.

## Como navegar

- `1.produto/`: visão, público, estratégia, métricas e prioridades.
- `2.dominios/`: requisitos funcionais por capacidade do produto.
- `3.transversais/`: regras que atravessam mais de um domínio.
- `4.ux/`: jornadas, fluxos e wireframes.
- `5.integracoes/`: contratos com sistemas externos.
- `6.entregas/`: especificações executáveis e backlog do MVP.

## Convenção

Cada funcionalidade deve registrar objetivo, escopo, atores, fluxo, regras de
negócio, dados, dependências, critérios de aceite e decisões em aberto. Quando
uma definição não existir, o documento deve registrar esse estado sem inferir
requisitos.

## Estado atual

O MVP prioriza descoberta → agendamento → atendimento concluído → avaliação.
E-commerce, telemedicina, emergência geolocalizada, lembretes e B2B são
evoluções posteriores.
