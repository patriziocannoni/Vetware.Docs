# Vetware — Documentação de Produto

Este repositório contém as especificações necessárias para implementar o MVP.

## Estrutura

- `1.produto/`: visão, escopo, métricas e sequência do MVP.
- `2.padroes/`: regras técnicas reutilizadas por vários MVPs.
- `3.mvp/`: uma especificação por entrega implementável.
- `.github/ISSUE_TEMPLATE/`: modelos para registrar e acompanhar entregas.

## Uso no desenvolvimento

Para implementar uma entrega, use o arquivo correspondente em `3.mvp/` e os
padrões aplicáveis em `2.padroes/`. Cada MVP identifica o que está definido e
o que exige refinamento antes do desenvolvimento.

O Design System Vetware está definido em `2.padroes/5.design-system-vetware.md`.
