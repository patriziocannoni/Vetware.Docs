# Vetware

Documentação e definição de escopo da plataforma Vetware, um ecossistema
digital para conectar clínicas veterinárias, pet shops, profissionais e tutores.

O projeto contempla autenticação e perfis de acesso, cadastro de
estabelecimentos e pets, busca de serviços, agendamento de atendimentos,
telemedicina, e-commerce de produtos, carteira digital do pet, avaliações e
integrações B2B. A plataforma também prevê recursos como geolocalização para
emergências, lembretes de saúde e programas de fidelidade.
