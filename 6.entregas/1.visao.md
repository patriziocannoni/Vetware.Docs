# Entregas do MVP

Cada diretório em `3.mvp/` representa uma entrega vertical identificada por `MVP-XXX`. A especificação é a referência normativa para implementação no frontend e backend.

## Fluxo de trabalho

1. Refinar a especificação.
2. Registrar uma GitHub Issue com links para a especificação.
3. Iniciar desenvolvimento após atender aos critérios de prontidão.
4. Vincular o pull request à issue.
5. Validar os critérios de aceite e encerrar a issue.

## Critério de prontidão

Objetivo, escopo, regras, contratos, critérios de aceite, dependências e decisões em aberto devem estar registrados.
