# MVP-001 — Especificação Backend

## Dependências

- Manter `spring-boot-starter-security`.
- Adicionar `spring-boot-starter-oauth2-resource-server`.
- Remover `spring-boot-starter-oauth2-authorization-server` do Backend, se presente.

## Configuração

- Criar `JwtConfig` em `br.com.vetware.backend.config`.
- Criar `JwtDecoder` com `NimbusJwtDecoder.withSecretKey(...)`.
- Criar `SecretKey` a partir de `spring.jwt.key`, UTF-8 e algoritmo `HmacSHA256`.
- Configurar `MacAlgorithm.HS256` e `JwtValidators.createDefaultWithIssuer("Vetware.Auth")`.
- Configurar `SecurityFilterChain` com CSRF desabilitado, sessão `STATELESS` e `oauth2ResourceServer().jwt(...)`.
- Aplicar `anyRequest().authenticated()` após as rotas de bypass.
- Implementar `CorsConfigurationSource` global que lê as origens do YAML do profile ativo.

Não usar `issuer-uri`, JWKS, OIDC discovery ou configuração Keycloak.
