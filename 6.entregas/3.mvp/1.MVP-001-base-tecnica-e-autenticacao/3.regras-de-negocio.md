# MVP-001 — Regras de Negócio

- Vetware.Auth é o único módulo emissor de tokens.
- Vetware.Backend aceita apenas JWT com assinatura HMAC-SHA256 válida.
- O claim `iss` deve ser exatamente `Vetware.Auth`.
- `exp` e `iat` devem ser válidos.
- O Backend não valida `aud`, pois o token atual não emite esse claim.
- `sub` e `scope` não autorizam recursos nesta entrega.
- Toda rota de negócio exige token válido, salvo bypass explícito.
- A origem CORS depende do profile ativo e não pode ser fixa no código Java.
