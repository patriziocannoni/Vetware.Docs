# MVP-001 — Cenários de Teste

## Token válido

Dado um token válido emitido pelo Vetware.Auth, quando uma rota de negócio receber `Authorization: Bearer <token>`, então o controller processa a requisição.

## Token ausente

Dada uma rota de negócio, quando a requisição não possuir `Authorization`, então a resposta é HTTP 401.

## Token inválido

Dado um token com assinatura alterada, issuer inválido ou expiração vencida, quando a rota de negócio for chamada, então a resposta é HTTP 401.

## CORS

Dada uma origem permitida no profile ativo, quando o navegador enviar preflight OPTIONS solicitando `Authorization`, então a resposta contém os headers CORS necessários e não exige token.
