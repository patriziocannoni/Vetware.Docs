# MVP-001 — Critérios de Aceite

- JWT válido emitido pelo Auth alcança o controller.
- Requisição sem Bearer recebe HTTP 401.
- Token expirado, adulterado ou de issuer diferente recebe HTTP 401.
- Swagger, actuator e bypasses declarados são acessíveis sem token.
- OPTIONS permitido pelo CORS não exige JWT.
- A origem CORS é definida no YAML do profile ativo.
- Vetware.Backend não emite JWT e não depende de Keycloak ou JWKS.
