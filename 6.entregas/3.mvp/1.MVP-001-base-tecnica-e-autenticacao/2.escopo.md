# MVP-001 — Escopo

## Incluído

- Configurar Vetware.Backend como OAuth 2.0 Resource Server.
- Validar JWT HS256 emitido por Vetware.Auth.
- Exigir Bearer JWT nos endpoints de negócio.
- Configurar CORS por profile para permitir `Authorization` vindo do Frontend.
- Liberar somente rotas de bypass declaradas.
- Retornar HTTP 401 para token ausente, inválido, expirado, adulterado ou com issuer diferente.

## Excluído

- Login, emissão de token, PasswordEncoder e credenciais no Vetware.Backend.
- JwtEncoder, JWKS, chave RSA/EC, OIDC discovery e Keycloak.
- Autorização fina por papel de negócio.
- Interceptor HTTP no Vetware.Frontend; será especificado em entrega própria.
