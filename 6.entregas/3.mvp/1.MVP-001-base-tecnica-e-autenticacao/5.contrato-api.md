# MVP-001 — Contrato de API

## Header de autenticação

```http
Authorization: Bearer <jwt>
```

| Propriedade | Regra |
| --- | --- |
| Algoritmo | HS256 |
| Chave | Valor de `spring.jwt.key` |
| Issuer | `Vetware.Auth` |
| Claims obrigatórios | `iss`, `iat`, `exp` |
| Claims atuais | `sub`, `scope` |

## Resultado das rotas de negócio

| Condição | Resultado |
| --- | --- |
| Sem Authorization | HTTP 401 |
| Token malformado ou assinatura inválida | HTTP 401 |
| Token expirado ou issuer inválido | HTTP 401 |
| Token válido | Controller processa a requisição |
| Preflight OPTIONS permitido | Não exige JWT |

Vetware.Auth mantém `POST /vetware-auth/auth/token` com `application/x-www-form-urlencoded`. O campo de resposta atual é `acessToken`.
