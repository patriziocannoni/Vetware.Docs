# MVP-007 — Confirmação e Conclusão de Atendimento

## Objetivo

Registrar a confirmação e o resultado operacional de um agendamento para permitir a medição de atendimentos concluídos.

## Escopo conhecido

O MVP prevê confirmação automática para reduzir no-show. Cancelamento, reagendamento, definição de no-show, canais de notificação, estados de conclusão, modelo de dados, API e critérios de aceite não estão especificados.

## Dependência

MVP-006.
