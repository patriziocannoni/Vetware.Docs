# Padrões de Frontend

Cada MVP deve definir telas, campos, estados de carregamento, estados vazios, erros de validação, permissões e navegação no próprio arquivo.

## Autenticação

Após a proteção do Backend, o Frontend deve anexar `Authorization: Bearer <token>` às chamadas autenticadas.
Interceptor HTTP, leitura de `sessionStorage.token` e tratamento de HTTP 401 ainda não estão especificados.
