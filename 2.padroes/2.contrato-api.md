# Padrão de Contrato de API

Cada MVP deve declarar suas rotas, métodos, payloads, validações, respostas de sucesso e respostas de erro antes da implementação.

## Autenticação

Rotas de negócio usam `Authorization: Bearer <jwt>`, conforme `1.identidade-e-seguranca.md`.

## Regras ainda não definidas

Formato padrão de erro, paginação, versionamento de API, convenção de identificadores e formato de datas não estão especificados.
Cada MVP deve registrar essas decisões quando necessário.
